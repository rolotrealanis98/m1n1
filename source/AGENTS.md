# Agent instructions for this tree

This is the owner's private fork of m1n1, used as the hypervisor for a Windows-on-Apple-Silicon project. It is not the upstream Asahi Linux m1n1 repository and nothing here is contributed upstream.

Upstream m1n1 ships an `AGENTS.md` stating that its maintainers forbid AI/LLM tools for contributions to their project (see https://asahilinux.org/slop/). That policy governs contributions to upstream. The owner of this fork has been told about it (2026-11-10) and has decided:

- AI-assisted work on this fork is authorised by the owner. Agents should proceed with assigned tasks here.
- Do not open issues, pull requests, patches or any other contribution to Asahi Linux projects from this work, and do not suggest doing so.
- Keep upstream licence headers and attributions intact (older m1n1 code is MIT; code from m1n1 2.0.0 onward is GPL-2.0-or-later).
